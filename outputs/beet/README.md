# Beet Processing Outputs

Representative outputs generated by the beet image-processing pipeline.

This directory is intended to contain examples of:

- Original RGB image
- Grayscale image
- Preprocessed image
- HSV representation
- Initial vegetation mask
- Morphologically cleaned mask
- Clipped vegetation image
- RGB and HSV histograms
- Extracted image features
- Classification result
- Classification overlay

The outputs stored here are generated from representative beet images used during system evaluation.
