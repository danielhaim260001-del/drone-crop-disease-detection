# Healthy Beet Samples

Representative healthy beet leaf images used for algorithm development and testing.

Crop: Beet
Class: Healthy
Source: Zenodo public dataset
Image type: RGB
Purpose: Reference samples for healthy beet leaf characteristics and comparison with diseased samples.

The exact Zenodo dataset record and citation are documented in the project dataset documentation.

Only representative sample images are stored in this repository. The complete external dataset is not redistributed here.
