# Beet Cercospora Leaf Spot Samples

Representative beet leaf images showing visual symptoms associated with Cercospora Leaf Spot used for algorithm development and testing.

Crop: Beet
Class: Diseased
Disease: Cercospora Leaf Spot
Source: Zenodo public dataset
Image type: RGB
Purpose: Reference samples for extracting and analyzing visual characteristics associated with Cercospora Leaf Spot.

The exact Zenodo dataset record and citation are documented in the project dataset documentation.

Only representative sample images are stored in this repository. The complete external dataset is not redistributed here.
