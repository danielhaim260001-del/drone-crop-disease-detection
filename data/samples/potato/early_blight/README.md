# Potato Early Blight Samples

Representative potato leaf images showing visual symptoms of Early Blight used for algorithm development and testing.

Crop: Potato
Class: Diseased
Disease: Early Blight
Source: PlantVillage Dataset
Image type: RGB
Purpose: Reference samples for extracting and analyzing visual characteristics associated with Early Blight.

Only representative sample images are stored in this repository. The complete external dataset is not redistributed here.
