# Potato Late Blight Samples

Representative potato leaf images showing visual symptoms of Late Blight used for algorithm development and testing.

Crop: Potato
Class: Diseased
Disease: Late Blight
Source: PlantVillage Dataset
Image type: RGB
Purpose: Reference samples for extracting and analyzing visual characteristics associated with Late Blight.

Only representative sample images are stored in this repository. The complete external dataset is not redistributed here.
